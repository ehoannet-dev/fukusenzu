器具写真の撮影

3D 部品づくりの参考写真を、器具ごと・向きごとに撮ります。写真は元の画質のままこの端末に保存され、「Mac へ送る設定」をしておくと自動で Mac へ送られます。

Mac へ送る設定

撮った写真は、GitHub にある自分だけの非公開リポジトリ kigu-photos へ 1 枚ずつ送られ、Mac の Claude がそこから取り込みます。設定はこの端末にだけ保存されます（端末ごとに 1 回）。

合言葉（トークン）の作り方（最初の 1 回だけ）
  1. ブラウザで github.com の「Fine-grained token を作る」ページを開く（ログインを求められたら GitHub にログイン）。
  2. Token name に「器具写真」など。Expiration は 1 年（期限が来たら同じ手順で作り直す）。
  3. Repository access で「Only select repositories」をえらび、kigu-photos を選ぶ。
  4. Permissions → Repository permissions → Contents を Read and write にする（ほかはそのまま）。
  5. 「Generate token」を押し、表示された github_pat_… で始まる長い文字列をコピーする（この画面を閉じると二度と見られません）。
  6. 上の「合言葉」に貼り付けて「保存して確かめる」。

この合言葉でできるのは kigu-photos へのファイルの追加・読み取りだけです。ほかのリポジトリや設定には使えません。

きれいに撮るコツ

  • フラッシュは OFF、ズームは 1 倍。ポートレートモードと超広角は使わない
  • 白か薄いグレーの紙の上に置き、器具は背景から 20cm 以上離す
  • 窓際の明るい日陰か、左右 2 方向からのライト。蛍光灯と日光を混ぜない
  • 器具を長押ししてピントと明るさを固定してから撮る（白い樹脂が白飛びしにくい）
  • 端子の接写は、刻印（W・接地側）が読めるところまで寄る
  • 寸法の写真は、ノギスか定規の目盛りが読めるように
  • 練習で使う前の、新品のうちに撮る

Mac での取り込み

Mac の Claude に「器具写真を取り込んで」と頼むと、~/Pictures/器具素材/raw/<器具>/01-front_日時.jpg のように器具ごとに保存されます。

送る設定をしない場合も、写真はこの端末に残ります。大きく表示して「ダウンロード」や「共有」で取り出せます。
