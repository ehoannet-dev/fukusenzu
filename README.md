# 複線図＆実配線トレーナー（第二種電気工事士）

配線図（単線図）を読み取って、**実際の電線を1本ずつ引き、ジョイントボックスの中で接続点をつくる**練習をするWebアプリです。
元ネタは「公表問題No.1 複線図解説」の板書（ホワイトボード左＝単線図／右＝複線図）。
**令和8年度の公表問題（候補問題）No.1〜No.13 の全13問**を収録しています（下の「収録問題」）。

## 使い方

`index.html` をブラウザで開くだけです（サーバー不要・インターネット接続不要）。

```bash
open index.html
```

ローカルサーバーで開きたいときは:

```bash
python3 -m http.server 8765
```

## 練習の流れ

### ① 支給ケーブルを切る

本番と同じで、ケーブルは**長いまま1〜2本で支給**されます。まず自分で切り分けます。

1. 材料バーの **「① 支給ケーブル」** から1つ**タップして選ぶ**（残りの長さが mm で出ます）。
2. **「ケーブルを切る」** を押す。
3. **どの区間ぶんを切るか**を選ぶ（図の寸法が出ます）。
4. **長さを4つから選ぶ**。正しい長さを選ぶと切れて、**「② 切ったケーブル」** に増えます。

> **切る長さ ＝ 図の寸法 ＋ 接続・結線する端ごとに 50mm**
> ジョイントボックスの中で接続する端と、器具に結線する端に 50mm ずつ足します。
> **電源側と施工省略側は切りっぱなし**なので足しません。
> 例：図の寸法 150mm でボックスと器具をつなぐ区間 → **250mm**。
>
> まちがった長さを選ぶと、**なぜ違うのかを説明して選び直させます**（切られません）。
> ※実際の試験では切断寸法の指定はありません。このアプリでは上の規則を「正解」としています。

### ② 切ったケーブルを置く

作業エリアには、ケーブルを置く場所が **点線の枠**（「ケーブルを選ぶ」）で示されています。
**その枠をタップする**と、**切ってあるケーブルが長さつきの一覧**で出るので、えらびます。
（「② 切ったケーブル」から枠へ **ドラッグ＆ドロップ**、材料をタップ → 枠をタップ でも置けます）
置いたケーブルの下には**長さ**が出ます。その区間に合わない長さだと**赤**で表示され、採点でも指摘されます。

- 置いたケーブルは **ジョイントボックスの入口に少し入った状態** で描かれます。
  心線は **ボックスの中の出口から接続点へ**、**外の出口から器具の端子へ** つながります（実物と同じ向き）。
- **ケーブルを置くまで、その区間には心線を通せません。**
- 支給本数は決まっています（EM-EEF2.0-2C×1／VVF1.6-2C×5／VVF1.6-3C×1）。
  **接続材料**（リングスリーブ／差込形コネクタ）は「接続材料」の見出しの下に並び、**使うたびに残りが減ります**。
  支給される種類と本数は問題ごとに違います（下の「収録問題」）。

> **画面のつくり**：スマホ・タブレットを**横向き**にすると、左に単線図、右に材料バーと作業エリアの**2列**になります。
> 材料は「ケーブル」「接続材料」で行が分かれ、狭いときは名前が短く（`EM2.0` `1.6-2C` `スリーブ小` など）表示されます。
>
> **スマホ／タブレットでの操作**：ケーブル置き・心線えらび・接続・削除・通電まで、**すべてタップだけ**でできます
> （ドラッグ＆ドロップやキーボードは、あればより速い、というだけの補助）。
> 横向きの低い画面・タブレットでは、左の「施工条件」「ワンポイント」「手順ガイド」「操作方法」は
> **最初たたまれていて**、見出しをタップすると開きます（作業エリアを広く使うため）。
> 「採点する」を押すと、**③採点結果まで自動でスクロール**します。
- 外すときはケーブルをクリック → **「このケーブルを外す」**（右クリックでも可）。

### ③ 心線をえらぶ

**ケーブルをクリック**（ケーブル本体でも名前の文字でもOK）すると、**心線の色（黒／白／赤）**が出ます。
えらぶと、その心線が **青く光って「えらんでいる」状態** になります。**この時点では電線は引かれません**（もう一度おすと取り消し）。

### ④ つなぎ先をクリック →「ここに接続する」

心線をえらんだまま、**器具の端子（青く光ります）をクリック**すると **「ここに接続する」** ボタンが出ます。
押すと、その心線が **ジョイントボックスからその端子まで** つながります。

### ⑤ ジョイントボックスの中でまとめる（接続点）

**心線を2本えらぶ**と **「接続する（2本）」** が出ます。押すと、その2本が **ボックスの中でつながり**、
リングスリーブの刻印（○／小／中）や差込形コネクタの本数用が自動で決まります（3本一度でもOK）。

- **接続点に足す**：**接続点をクリック** → 心線をえらぶ → **「この接続点に追加」**。
- ボックスの中の **線端をクリック** してえらぶこともできます。
- **③と④はどちらが先でもOK**。先にボックスの中でまとめた場合、器具につないでいない端は **赤い丸** で示されます。
  あとからその心線をえらんで端子をクリックすれば、そこにつながります（採点でも指摘されます）。

### 渡り線（点滅器どうし）

ケーブルを使わない区間なので、**端子をクリック → となりの端子をクリック** で引きます。

### まちがえたとき（1つ前に戻す）

| やりたいこと | 操作 |
|---|---|
| えらんだ心線を取り消す | もう一度その色をえらぶ／何もない所をクリック |
| つなぎ目を1つだけ外す | **その線をクリック** → **×**。接続点との線なら**その心線だけスリーブから外れ**（スリーブも他の心線も残る／刻印は自動で変わる）、器具への線なら**端子から外れる**（電線は残る）。`Delete`／**右クリック**でも可 |
| 心線ごと消す | ケーブルをクリック → 一覧の **✕** |
| 外した心線をまた付ける | **接続点をクリック** → 心線をえらぶ → **「この接続点に追加」** |
| 接続点から1本だけ外す | 右のリストのメンバー行の **✕**（図の上でその線端を**右クリック**でも可） |
| 接続点をまるごとはずす | 接続点をクリック → **×**（右クリックでも可） |
| ケーブルを外す | ケーブルをクリック → **「このケーブルを外す」**（右クリックでも可） |
| とにかく元に戻す | **元に戻す**ボタン / `⌘Z`。押すたびに「電線 3本 → 2本」のように**何が変わったか**を表示します |
| 全部消してやり直す | **「1からやり直す」** を**2回押し**（1回目で「もう一度押すと全部消えます」に変わり、5秒で取り消し） |

削除はすべて取り消せます。配線は自動保存されるので、閉じても続きからできます。

## 実装している「本物のルール」

- **材料選び**：区間ごとに正しいケーブルを選ぶところから始まります。支給本数は有限で、置いた本数だけ減ります。
- **ケーブルの心線構成**：置いたケーブルの心線しか通せません（`VVF1.6-2C`なら黒・白各1本）。
  「黒を共通に使ったから、帰り線は残った白」という考え方がそのまま制約になります。
- **極性**：ランプレセプタクルの受金ねじ部端子・引掛シーリングの接地側極端子には白（接地側）。逆にすると欠陥。
- **接地側は負荷へ直行／非接地側はスイッチへ**：この問題では全ての器具が点滅器で制御されるため、白をスイッチに入れる／黒を器具に直結すると欠陥になります（コンセントや常時点灯のパイロットランプがある問題では、黒を器具に直結するのが正解です）。
- **帰り線の色別は問わない**（公式解答どおり）。ただし電源からの接地側は白、点滅器までの非接地側は黒は必須。
- **端子に入る本数**：連用スイッチの電源側端子は2本まで（渡り線の送り）、器具の端子は1本まで。
- **リングスリーブの刻印**（○／小／中）と**差込形コネクタの本数**（**差コネ2／差コネ3**と表示）を自動判定。
  1.6×2＝小・○／1.6×3〜4＝小・小／2.0×1＋1.6×1〜2＝小・小／2.0×2＝小・小／
  1.6×5〜6＝中・中／2.0×1＋1.6×3〜5＝中・中／2.0×2＋1.6×1〜3＝中・中／2.0×3〜4＝中・中（表にない組合せは「適用外」）。
  公表問題No.1は **A部分＝リングスリーブ5か所／B部分＝差込形コネクタ3か所**。
- **位置表示灯内蔵スイッチ（ホタル）**「イ」は、**スイッチを切っているときに点灯**（異時点滅）します。
- **ジョイントボックス**は実物（アウトレットボックス）と同じ **四角** で描いています（破線＝ボックスは省略という意味）。
- **電源部分は EM-EEF2.0-2C**（エコケーブル）。No.1 ではここだけ VVF ではありません。

### 公表問題 No.7

**3路スイッチ2個＋4路スイッチ1個**で、ランプレセプタクル「イ」2灯（1灯は施工省略）を**3か所から点滅**。
**A＝VVF用ジョイントボックス・リングスリーブ**／**B＝アウトレットボックス・差込形コネクタ**。

- 支給材料：VVF2.0-2C 250mm×1／VVF1.6-2C 1400mm×1／VVF1.6-3C 1150mm×1、リングスリーブ「小」×6、差コネ2×4・差コネ3×2
- 正解の接続：A＝スリーブ4か所（**小・小・○・○**）／B＝コネクタ6か所（**3本用×2・2本用×4**）
- ポイント
  - **4路スイッチは 1–2・3–4 ⇔ 1–4・3–2 で切り替わる**。同じ3路から来た2本は **1と3**（または2と4）に入れる。1と2に分けると点かない位置ができる。
  - B→4路 は **VVF1.6-2C が2本**（同じ区間に2本置く）。
  - どのスイッチを1回切り替えても、2灯そろって点滅が反転すれば正解。

### 公表問題 No.8

**リモコンリレー3個（6極の端子台で代用）**で、引掛シーリングローゼット（丸形）「イ」・ランプレセプタクル「ロ」・引掛シーリング「ハ」（施工省略）を**個別に入り切り**。
電源は **VVR2.0-2C（丸形）**、ジョイントボックスは**アウトレットボックス1個**。

- 支給材料：VVR2.0-2C 300mm×1／VVF1.6-2C 1100mm×**2**、リングスリーブ「小」×5（実使用3）、差コネ4×2
- 正解の接続：**4本の接続（黒4本・白4本）だけ差込形コネクタ4本用**、帰り線2本の3か所は**リングスリーブ「小」・刻印○**
- ポイント
  - **各リモコンリレーへは2心ケーブル1本**（黒で行って白で戻る）。リレーの2端子は片切スイッチと同じで、上下を入れ替えても正解。
  - ボックスの中で「リレーから戻る白」と「器具へ行く黒」をつなぐ（**白と黒をつなぐ**のがこの問題の特徴）。
  - VVF1.6-2C は2本支給。**1本の中から切り出す**（2本にまたがる長さは切れない）。

### 公表問題 No.10

## 問題を追加するには

`js/problems/noNN.js` を1つ作り、`window.PROBLEMS.push(問題)` で足して、`index.html` に `<script>` を1行加えます。主なキー：

| キー | 意味 |
|---|---|
| `single` | 左に表示する単線図（線と記号の座標） |
| `devices` | 作業エリアの器具。`terminals[].kind` が採点の意味づけ（`load-n` `load-x` `sw-com` `sw-load` など） |
| `runs` | ケーブルを置く区間。`slots`（何本置くか）／`need`（正しい種類。配列なら置き場の順は問わない＝管の中の IV）／`span`（図の寸法）／`cut`（切る長さ）／`at`（置き場ラベルの座標）／`free`（渡り線）／`conduit`（金属管・PF管） |
| `supply.cables` | 支給されるケーブルの長さと本数（材料表どおり。`{'vvf16-2c': { len: 900, count: 2 }, ...}`） |
| `pairs` | 点滅器と負荷の対応 |
| `answer` | 模範解答の電線と接続点、解説 |

採点は**模範解答との一致ではなく回路の成立とルール**で行うため、別解も正解になります。
足したら `node tools/check-problems.js` が全問 ✅ になることを確かめてください（詳しい手順と落とし穴は `docs/作り方と注意点.md` の16章）。
